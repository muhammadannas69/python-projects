# Employee Management System

This is a simple command-line Employee Management System built with Python.

The program stores employee records in a dictionary and allows users to add, search, update, and delete employees through a menu-driven interface. It also uses exception handling to manage invalid input and common errors.

## Features

- Add a new employee
- Search for an employee
- Update employee salary
- Delete an employee
- View all employees
- Exit the program
- Prevent duplicate employee records
- Handle invalid salary input
- Handle invalid menu choices
- Display appropriate error messages

## Concepts Used

- Dictionaries
- Loops
- Conditional Statements
- Functions (optional if added later)
- Exception Handling (`try-except`)
- Input Validation

## How to Run

```bash
python employee_management_system.py
```

## Example

```
Employee Management System

1. Add Employee
2. Search Employee
3. Update Salary
4. Delete Employee
5. View Employees
6. Exit

Enter option: 1

Enter employee name: Ali
Enter salary: 50000

Employee added successfully.
```
